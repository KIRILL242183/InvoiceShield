# Обновление v0.3 → v0.4 на Mac

1. Остановите Uvicorn (`Control+C`).
2. Сохраните резервную копию локального `invoiceshield.db` вне репозитория.
3. Распакуйте `InvoiceShield-v0.4.0-update.zip` поверх текущей папки проекта.
4. В активном виртуальном окружении выполните `python -m pip install -r requirements-dev.txt`.
5. Выполните `python -m pytest -q` (ожидается 46 тестов).
6. Запустите `python -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8000`.
7. После входа откройте `/pdf-import` и загрузите тестовый текстовый PDF.

Новая версия не требует миграции БД; таблицы данных не менялись. Используйте только синтетические счета.
