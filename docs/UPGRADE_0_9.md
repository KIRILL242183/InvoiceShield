# Обновление v0.8 → v0.9 на macOS

Таблицы и формат базы не менялись.

1. Останови сервер (Control+C).
2. Сделай резервную копию `invoiceshield.db` вне репозитория.
3. Распакуй `InvoiceShield-v0.9.0-update.zip` поверх текущего кода, не удаляя `.venv` и базу.
4. Активируй окружение и выполни `python -m pip install -r requirements-dev.txt`.
5. Выполни `python -m pytest -q`, затем `python -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8000`.
6. Проверь главную, аналитику, расследования, импорт PDF, вход и навигацию.

Если база хранится по другому пути, сначала проверь `DATABASE_URL`, не перезаписывай случайные файлы.
