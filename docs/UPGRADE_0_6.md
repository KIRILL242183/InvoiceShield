# Обновление InvoiceShield 0.5 → 0.6 (macOS/Linux)

1. Остановить Uvicorn комбинацией Control+C.
2. Сохранить локальную базу вне репозитория (в типовой установке — `invoiceshield.db`).
3. Распаковать архив `InvoiceShield-v0.6.0-update.zip` поверх старого проекта, не удаляя `.venv` и БД.
4. Активировать `.venv` и выполнить `python -m pip install -r requirements-dev.txt`.
5. Выполнить `python -m pytest -q` — ожидается 83 теста.
6. Запустить `python -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8000`.
7. Войти в приложение и открыть `http://127.0.0.1:8000/analytics`.

Миграция схемы не требуется: добавлены только маршруты, сервис, шаблон и CSS.
Учебный прототип рассчитан на синтетические данные и локальный запуск. CSV экспортирует данные счетов, поэтому доступен только администратору.
