# Обновление InvoiceShield v0.6 → v0.7

1. Остановите Uvicorn (`Control+C`) и сделайте резервную копию `invoiceshield.db` за пределами папки проекта.
2. Распакуйте `InvoiceShield-v0.7.0-update.zip` поверх существующей папки.
3. Активируйте `.venv` и запустите `python -m pip install -r requirements-dev.txt`.
4. Проверьте `python -m pytest -q` — ожидается 93 успешных теста.
5. Запустите `python -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8000`.
6. `/health` сообщает о жизни процесса, `/ready` проверяет БД.

Новая таблица `login_throttles` создаётся `Base.metadata.create_all()` при запуске. Существующие аккаунты, сессии, счета и расследования не удаляются. Это учебный локальный сервис, не публикуйте его в интернет с реальными документами без security review.

После пяти неудачных входов — блокировка на 15 минут. По окончании блокировки доступ восстанавливается автоматически; корректный пароль до этого не разблокирует вход. Устаревшие (но не активные) счётчики можно удалить: `python -m scripts.prune_login_throttles`.
