# Публикация и происхождение Git-истории

## Происхождение

28 октября 2026 года существующие версии InvoiceShield v0.1.0, v0.1.1, v0.2.0 и v0.3.0
были импортированы в Git из архивов, сохранённых на предыдущих этапах разработки проекта.
Каждому снимку соответствует отдельный коммит и аннотированный тег, чтобы видеть техническую эволюцию:
первую версию антифрода, устранение race condition, RBAC/CSRF и управление расследованиями.

**Это ретроспективный импорт снимков кода, а не исходный дневник Git-разработки.**
Даты коммитов не изменялись задним числом. Будущие изменения рекомендуется делать небольшими
коммитами после проверки тестов и самостоятельного разбора кода.

## Что нельзя публиковать

- Файлы `.env` и реальные ключи, токены, пароли.
- Файлы `*.db`, `*.sqlite*`, их журналы и резервные копии.
- Локальное окружение `.venv`, кэш Python и тестов.
- Документы клиентов, настоящие банковские реквизиты и любые персональные данные.

В Git хранится `.env.example` только с примером **заменяемого** пароля для локального Docker.
Перед публикацией обязательно проверяйте `git status --short` и `git ls-files`.

## Назначение

Проект учебный, рассчитан на запуск исключительно в локальном окружении.
Без отдельного аудита безопасности его нельзя использовать для обработки реальных платежей.
