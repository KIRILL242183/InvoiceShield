# Как разбирать проект, чтобы понимать код

## Модуль 1: Запуск и запросы
1. Изучи `app/main.py`: FastAPI-приложение, роутеры и lifespan.
2. Открой `/docs` и отправь GET `/health`.
3. Изучи `app/routes_api.py`: почему POST поставщика отвечает 201, а ошибка — 409.
4. Измени `title` приложения и проверь новый заголовок Swagger.

## Модуль 2: База и деньги
1. Изучи `app/models.py`: разница между Supplier, Invoice и AuditEvent.
2. Объясни, почему `amount_kopecks` — integer вместо `float`.
3. Найди в `app/database.py`, как открывается и закрывается сессия.
4. Проверь, где одна транзакция объединяет создание счёта и запись события.

## Модуль 3: Антифрод
1. Изучи `services/risk.py` и вычисли баллы вручную.
2. Создай счёт с другим счётом получателя и объясни +70.
3. Повтори номер у того же поставщика и объясни +60.
4. Усложнение: добавь отдельное правило про сумму, изменив тест и код.

## Модуль 4: Тесты и Git
1. Запусти `python -m pytest -q`.
2. Измени ожидаемый балл в тесте — получи красный тест, верни обратно.
3. Сделай первый коммит, а исправление — вторым.
4. Научись читать `git diff`, `git status`, `git log --oneline`.
